# 하영 고라보게 — 다섯 문항 · 연필 엽서

Claude가 이 폴더에서 일할 때 지킬 것. 다른 컴퓨터에서도 같은 기준으로 이어 가려고 적어 둠. 고치는 곳 · 이벤트 목록 · 올리는 법은 README.md.

## 말하기

- 사용자에게 보이는 글은 전부 한국어. 맺음 상자(요약 · 질문 · 단추)도 한국어. 어려운 말은 쉬운 말로 풀어 씀.

## 프로젝트

- 「하영 고라보게」: 제주 여행자가 제주어로 엽서를 쓰게 하는 한경 LX 웹진. 웹진 lxwebzine.hankyung.com/2026-1/team1/ · 엽서 사이트 …/play/postcard/ · 저장소 github.com/gamboyartmad-commits/webzine
- KPI: 활성 사용자 1,000명, 평균 체류 2분. 핵심 전환은 `cta_click` · `pc_send_done`.
- 이 폴더는 빌드 없는 정적 사이트. 루트 = 다섯 문항 「ᄆᆞ음 고라보게」, `pencil/` = 연필로 쓰는 엽서, `carousel/` = 인스타 캐러셀 작업 도구(배포 안 함).

## 원칙

- 지어내지 않기: 가짜 날짜 · 출처 금지, 예시는 예시라고 밝힘. 제주어 낱말은 사전(개정증보 제주어사전 2009) 쪽수로 근거를 남김(`jeju-extra.js`). 사전 PDF는 텍스트로 뽑으면 아래아가 빠지니 쪽 이미지로 확인.
- 장식은 덜기. 사용자는 빼기 · 되돌리기를 자주 고름.
- 측정은 `track.js`의 `hyTrack`. 이벤트 이름은 `pc_`로 시작하고, 사람이 쓴 글(메모 · 손글씨 · 이름)은 담지 않음. 새 이벤트를 만들면 README의 이벤트 목록에 더함.
- 측정 값(`GTM_ID` 등)과 카카오 키는 엽서 사이트 `config.js`와 같게 둠. HTML에 GTM 코드를 따로 붙이지 않음(두 번 셈).
- `translate.js` · `jeju-dict.js` · `badwords.js` · `track.js`는 엽서 사이트 복사본이라 직접 고치지 않음.
- 파일을 고치면 HTML의 `?v=` 숫자를 올려 브라우저 캐시를 피함.

## 미리 보기

- 이 폴더에서 `python3 -m http.server 4181 --bind 127.0.0.1` → http://127.0.0.1:4181/ (다섯 문항) · http://127.0.0.1:4181/pencil/ (연필 엽서)
- 내 컴퓨터에서는 측정 · 카카오톡이 꺼져 있음(`config.js`). 이벤트 확인은 주소 끝에 `?track-debug`, 따라 쓰기 점수 맞추기는 `?score-debug`.
- 사용자가 미리보기에서 직접 써 둔 손글씨가 있을 수 있음. 시험 전에 localStorage `hy-pencil-desk-v1` · `hy-pencil-desk-photo`를 따로 두었다가 끝나면 되돌릴 것.
